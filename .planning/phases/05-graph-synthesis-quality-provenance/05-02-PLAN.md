  <action>
    Create `lib/pipeline/provenance.ts` exporting:
    - `type ProvenanceValidationResult = { payload: SemanticUniversePayload; resultType: ResultType; reason?: string; rejectedLinks: number; rejectedNodes: number; repairedLinks: number; groundedEdgeCount: number; passageEvidenceCount: number }`
    - `validateGraphProvenance(payload: SemanticUniversePayload, opts?: { minimumNodes?: number; minimumGroundedEdges?: number; minimumEvidence?: number }): ProvenanceValidationResult`

    Required validator behavior:
    - Unknown `evidenceIds` are removed from nodes, links, discourse, visuals, and model-strength models.
    - Unknown `sourceIds` are removed from nodes and links.
    - Link `sourceIds` are derived from cited evidence `sourceId` values when missing.
    - Every link must have at least one valid `evidenceId` after normalization.
    - Link repair runs once by deterministic lexical overlap using link source label, target label, `dominantCompetitor`, and passage `excerpt`/`aiResponse`/`query`/`sourceTitle`.
    - If repair fails, reject the link.
    - Every non-brand node must have valid evidence after derivation or repair; reject unsupported generated nodes and attached links.
    - Return `resultType: "degraded"` when any link/node is rejected or any link is repaired.
    - Return `resultType: "fallback"` and reason `below_grounded_graph_floor` when validated payload has fewer than 4 nodes, fewer than 3 grounded links, or fewer than 3 passage evidence items.

    Add tests for pass, derive `sourceIds`, repair once, reject unsupported link, reject unsupported non-brand node, and fallback floor.
  </action>

    <automated>npx vitest run lib/pipeline/__tests__/provenance.test.ts</automated>
