    function entityFillColor(node: GraphNode): string {
      if (node.entityType && node.entityType in ENTITY_TYPE_COLORS) {
        return ENTITY_TYPE_COLORS[node.entityType];
      }
      return ENTITY_TYPE_FALLBACK_COLOR;

      if (link.missing) return 2;
      if (link.relType === "causal") return 3.5;

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline output -> sigma renderer | entityType / relType strings (already whitelisted by Plan 01) used as keys into color/size maps |
| sigma WebGL canvas -> DOM | label rendering happens via WebGL canvas text, not innerHTML |
| FA2 web worker -> main thread | worker lifecycle must terminate on unmount or CPU leaks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | entityType color lookup | mitigate | `entityFillColor(node)` checks `node.entityType in ENTITY_TYPE_COLORS` before lookup; returns `#64748b` slate fallback for undefined or unknown values. Plan 01 already whitelists at the pipeline boundary; this is defense in depth. |
| T-06-02 | Tampering | relType edge style lookup | mitigate | `edgeSizeForLink` / `edgeColorForLink` use explicit `if (link.relType === "...")` checks; default branch (any other value, including undefined) returns the contextual style. No object indexing on untrusted strings. |
| T-06-03 | Tampering / XSS | sigma node label rendering | accept | sigma v3 renders labels through WebGL canvas text drawing — no innerHTML, no DOM injection path. Confirmed by RESEARCH.md Security Domain. No additional mitigation. |
| T-06-04 | Denial of Service | FA2 worker leak after unmount | mitigate | `LayoutAndCommunityController` cleanup function calls `clearTimeout(timer); stop(); kill();` per Pitfall 5. Worker is bounded by FA2_STOP_TIMEOUT_MS (6000ms) auto-stop even when component remains mounted. |
| T-06-05 | Information disclosure | sigma error stack traces | accept | Errors logged to console with `[semantic-graph]` prefix only — no user-visible error text exposed; no sensitive data in stack traces (sigma operates only on already-public graph data). |
</threat_model>
